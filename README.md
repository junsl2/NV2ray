# NV2ray

A black Liquid Glass-inspired macOS menu-bar networking prototype with VLESS, Hysteria2, custom DNS, and rule-based routing.

## Supported profile types

- VLESS: None, TLS, Reality
- VLESS transports: TCP, WebSocket, HTTP, XHTTP
- Hysteria2: TLS, TCP/UDP selection, bandwidth limits, port ranges, port hopping, Salamander or Gecko obfuscation

The SwiftUI interface, profile validation, persistence, settings export, DNS options, and routing editor are implemented. A signed Network Extension target and an embedded sing-box core are still required for a working system-wide connection.
